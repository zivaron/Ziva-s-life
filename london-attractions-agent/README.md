# סוכן האטרקציות של זיווה בלונדון

סוכן אינטראקטיבי בשורת פקודה (Python) שממליץ על אטרקציות בלונדון.

## הרצה

```bash
python3 agent.py
```

לא נדרשות ספריות חיצוניות - רק Python 3.

## מה הסוכן יודע לעשות

1. להציג את כל האטרקציות במאגר (20 אטרקציות מוכרות בלונדון).
2. לסנן לפי קטגוריה (היסטוריה, מוזיאונים, טבע ופארקים, קניות ואוכל, נוף ובידור).
3. לסנן לפי אזור בעיר.
4. לסנן לפי רמת תקציב (חינם / בינוני / יקר).
5. לבנות מסלול טיול מותאם אישית לפי מספר ימים, שעות פנאי ליום, והאם הטיול כולל ילדים.
6. להציע אטרקציה אקראית ("הפתעה").
7. לחפש אטרקציה לפי שם.

## מבנה הפרויקט

- `agent.py` - לוגיקת הסוכן והתפריט האינטראקטיבי.
- `attractions_data.py` - מאגר הנתונים של האטרקציות.
