# Ziva-s-life

זוהי תקיית הפרויקט של החיים שלי שבתוכה יהיו מלא פרויקטים קטנים כמו סאני, עבודה, ברידג' וכו'.

## איך נעבוד ביחד

את לא צריכה לדעת שום דבר טכני כדי לעבוד איתי (Claude). פשוט תכתבי לי בשיחה, במילים שלך, מה את רוצה לעשות - ואני אדאג לכל השאר: יצירת קבצים, עריכה, שמירה, ו"פרסום" השינויים (בשפה טכנית זה נקרא "קומיט" ו-"פוש" - אבל את לא צריכה לזכור את זה, זה התפקיד שלי).

כל מה שצריך זה:
1. לספר לי מה רוצים לעשות או לשנות.
2. אני עושה את זה ומראה לך מה יצא.
3. אם זה טוב - זהו, זה נשמר. אם צריך שינויים - פשוט מבקשים.
