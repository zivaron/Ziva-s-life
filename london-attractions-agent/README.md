# london-attractions-agent

סוכן שיעזור לזיוה למצוא אטרקציות מפורטות בלונדון שמתאימות להעדפות שלה.

זהו עדיין רק פלייסהולדר. בפעם שנשב לעבוד על הפרויקט הזה נחליט יחד על דברים כמו:
- מה בדיוק זיוה אוהבת ומחפשת (סוג אטרקציות, תחומי עניין).
- איך היא רוצה לקבל את ההמלצות (שיחה, רשימה, מסמך).
- מאיפה יגיע המידע על האטרקציות בלונדון.
