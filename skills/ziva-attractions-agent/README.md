# טבלת זיווה — סוכן אטרקציות אישי

זהו קובץ ה"סקיל" (`SKILL.md`) שהופך את הסוכן הזה לזמין מכל שיחה רגילה ב-**Claude.ai chat**
(לא רק ב-Claude Code), פשוט על ידי אמירת "**טבלת זיווה**" או "**סוכן האטרקציות שלי**".

## איך מתקינים את זה ב-Claude.ai

### אופציה א׳ — Custom Skill (מומלץ, אם יש לך גישה לפיצ'ר Skills)
1. ב-claude.ai: **Settings → Capabilities → Skills**.
2. העלי את התיקייה הזו (`ziva-attractions-agent`) כולה, או רק את `SKILL.md`.
3. מרגע זה, בכל שיחה חדשה, אמירת "טבלת זיווה" או "סוכן האטרקציות שלי" תפעיל את הסוכן
   אוטומטית עם כל ההקשר האישי שכבר מוגדר בקובץ.

### אופציה ב׳ — Project instructions (עובד בכל תוכנית, גם בלי Skills)
1. ב-claude.ai צרי **Project** חדש בשם "טבלת זיווה".
2. ב-**Project knowledge** העלי את קובץ `SKILL.md`.
3. ב-**Custom instructions** של הפרויקט הדביקי הפניה קצרה: "פעלי לפי ההנחיות בקובץ
   ziva-attractions-agent/SKILL.md בכל פעם שאני מבקשת 'טבלת זיווה'."
4. מעכשיו, כל שיחה בתוך הפרויקט הזה תכיר את ההקשר — פשוט תכתבי "טבלת זיווה" עם
   הבקשה שלך (מיקום, נושא, גילאים, תאריכים).

### עדכון ההקשר האישי
ההקשר האישי (גיל הנכדה, הטעם המשפחתי, המיקום הנוכחי) שמור בתוך `SKILL.md` עצמו.
כשמשהו משתנה (מיקום חדש, ילד נוסף, טעם חדש) — פשוט ערכי את הקובץ, או בקשי מ-Claude
Code לעדכן אותו בשיחה הבאה כאן בריפו.

## מה זה עושה בפועל
בכל הפעלה, הסוכן:
1. קורא קודם את `PROFILE.md` — הזיכרון המצטבר שלך (קטגוריות, פריטים שאהבת, שיטות עבודה).
2. אוסף את הפרטים החסרים (מיקום / נושא / גילאים / תאריכים) בשאלה קצרה אחת.
3. יוצא לחיפוש אמיתי באינטרנט (לא ממציא לינקים או מחירים).
4. מחזיר **טבלה נפרדת לכל קטגוריה** שהגדרת בעצמך (למשל "ילדים"), עם: דירוג, שם+לינק,
   תיאור, "למה מתאים לך", תאריכים, שעות, מחיר, מיקום ונסיעה, והתאמת גיל/טיפים.
5. מזהה חיזוק חיובי ממך ("אהבתי", "זה עבד מצוין" וכו') ומוסיף אותו ל-`PROFILE.md`
   — כך שההמלצה הבאה כבר "יודעת" מה עבד.
6. אותו מנגנון מתאים גם לנושאים עתידיים מעבר לאטרקציות (מסעדות, פעילויות וכו').

### חשוב לדעת על הלמידה האוטומטית
עדכון אמיתי של `PROFILE.md` דורש שלסוכן תהיה **גישת כתיבה בפועל לריפו** — כלומר
דרך Claude Code (כמו בהפעלה הזו), או דרך צ'אט רגיל ב-claude.ai **עם GitHub connector
מחובר ומאושר לריפו הזה**. בצ'אט רגיל בלי חיבור כזה, הסוכן לא באמת יכול לכתוב לקובץ —
הוא יציג לך בסוף התשובה הצעת עדכון ("🧠 עדכון פרופיל מוצע") שתוכלי להעביר הלאה
(להדביק ב-Project knowledge, או לבקש ממני לעדכן בהפעלה הבאה כאן).

דוגמה חיה מההפעלה הראשונה (לונדון + ציר אוקספורד, יולי 2026) נמצאת כ-Artifact בשיחה
שבה נוצר הסקיל הזה.
