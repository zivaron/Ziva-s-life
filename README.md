# Ziva-s-life

זוהי תקיית הפרויקט של החיים שלי שבתוכו יהיו מלא פרויקטים קטנים כמו סאני, עבודה , ברידג וכו

---

## פרויקט: "סאני וחבורת חמשת הכוחות"

ספר ילדים מאת זיוה רון. 2,686 מילים, 7 פרקים, 6 דמויות ילדים.

### מבנה התיקיות

| תיקייה | מה יש בה |
|---|---|
| `manuscript/` | כתב היד המקורי (`.docx`) וגרסת טקסט נקייה לעיון והשוואה |
| `analysis/` | שני מסמכי הניתוח והעריכה |
| `tools/` | סקריפטים שמייצרים את מסמכי הניתוח |

### המסמכים

**`analysis/01_ניתוח_ספרותי_מקיף.docx`** — ניתוח מלא מ־20 בחינות, מסודרות בחמש
משפחות (סיפור · דמויות · שפה · משמעות · הפקה). כולל חוות דעת, ניתוח סאבטקסט,
תוכנית פעולה מדורגת, מפת פרישות לאיור ובריף לאייר.

**`analysis/02_הטקסט_עם_הערות_עריכה.docx`** — הטקסט המקורי במלואו עם 64 הערות
משובצות במקומן, שתי טבלאות תיקונים (21 תיקוני לשון ועקביות), ארבעה קטעים
משוכתבים לדוגמה, גרסה חלופית לשיר, ושתי סצנות חדשות מנוסחות במלואן.

### בנייה מחדש

```bash
npm install
node tools/build_analysis.js
node tools/build_annotated.js
```

הסקריפטים משתמשים ב-`tools/lib_docx.js` — עוטף קצר סביב `docx` (npm) שמטפל
בעברית מימין לשמאל: `bidirectional` בפסקאות, `rightToLeft` בריצות, וטבלאות
`visuallyRightToLeft`.
