# Ziva-s-life

זוהי תקיית הפרויקט של החיים שלי שבתוכה יהיו מלא פרויקטים קטנים כמו סאני, עבודה, ברידג' וכו'.

## איך נעבוד ביחד

את לא צריכה לדעת שום דבר טכני כדי לעבוד איתי (Claude). פשוט תכתבי לי בשיחה, במילים שלך, מה את רוצה לעשות - ואני אדאג לכל השאר: יצירת קבצים, עריכה, שמירה, ו"פרסום" השינויים (בשפה טכנית זה נקרא "קומיט" ו-"פוש" - אבל את לא צריכה לזכור את זה, זה התפקיד שלי).

כל מה שצריך זה:
1. לספר לי מה רוצים לעשות או לשנות.
2. אני עושה את זה ומראה לך מה יצא.
3. אם זה טוב - זהו, זה נשמר. אם צריך שינויים - פשוט מבקשים.

## הפרויקטים בריפו

- [`zani-book`](./zani-book) - ספר שאני מציירת/כותבת לנכדה שלי, זני.
- [`london-attractions-agent`](./london-attractions-agent) - סוכן שעוזר לי למצוא אטרקציות מפורטות בלונדון שמתאימות למה שאני אוהבת.
- [`skills/ziva-attractions-agent`](./skills/ziva-attractions-agent) - סקיל להמלצות אטרקציות מותאמות אישית.
- "סאני וחבורת חמשת הכוחות" - ספר ילדים (פירוט בהמשך).

פרויקטים נוספים (עבודה, ברידג' וכו') יתווספו כאן כשנתחיל לעבוד עליהם בפועל.

## פרויקט: "סאני וחבורת חמשת הכוחות"

ספר ילדים מאת זיוה רון. 2,686 מילים, 7 פרקים, 6 דמויות ילדים.

### מבנה התיקיות

| תיקייה | מה יש בה |
|---|---|
| `manuscript/` | כתב היד המקורי (`.docx`) וגרסת טקסט נקייה לעיון והשוואה |
| `analysis/` | מסמכי הניתוח והעריכה |
| `tools/` | סקריפטים שמייצרים את מסמכי הניתוח |
| `web/` | הספר כדף קריאה |

### המסמכים

**`analysis/01_ניתוח_ספרותי_מקיף.docx`** — ניתוח מלא מ־20 בחינות, מסודרות בחמש
משפחות (סיפור · דמויות · שפה · משמעות · הפקה). כולל חוות דעת, ניתוח סאבטקסט,
תוכנית פעולה מדורגת, מפת פרישות לאיור ובריף לאייר.

**`analysis/02_הטקסט_עם_הערות_עריכה.docx`** — הטקסט המקורי במלואו עם 64 הערות
משובצות במקומן, שתי טבלאות תיקונים (21 תיקוני לשון ועקביות), ארבעה קטעים
משוכתבים לדוגמה, גרסה חלופית לשיר, ושתי סצנות חדשות מנוסחות במלואן.

### בנייה מחדש

```bash
npm install
node tools/build_analysis.js
node tools/build_annotated.js
```

הסקריפטים משתמשים ב-`tools/lib_docx.js` — עוטף קצר סביב `docx` (npm) שמטפל
בעברית מימין לשמאל: `bidirectional` בפסקאות, `rightToLeft` בריצות, וטבלאות
`visuallyRightToLeft`.
